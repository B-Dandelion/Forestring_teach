# 포레스트링 선생님 v3 완성형 작업 계획

## 목표

현재 v3의 Supabase 기반 일정 조회/변경 구조를 유지하면서 운영에 필요한 관리 기능을 완성한다.

핵심 원칙:

- Flutter / Dart 고정
- `teacher`는 조회 전용
- `manager`는 자기 지점만 관리
- `master`는 전체 지점 관리
- 중요한 데이터 변경은 앱에서 테이블을 직접 조합해 처리하지 않고 RPC / Edge Function을 사용
- 마스터/지점장 화면을 복제하지 않고 같은 화면에 권한 scope만 적용
- 지점, 선생님, 학생 목록은 이름순 정렬
- 기존 `ver2` 코드는 기능 요구사항 참고용으로만 사용

## Phase 1. 수강생 관리

정식 메뉴 `수강생 관리`를 추가한다.

필수 기능:

- 지점별 수강생 목록
- 이름 검색
- 담당 선생님 / 학생 유형 / 재원 상태 필터
- 수강생 상세
- 이름 수정
- PIN 재설정
- 담당 선생님 변경
- 정규 스케줄 조회
- 정규 스케줄 변경
- 학생별 월간 수업 내역
- 퇴원 / 비활성화
- 신규 정규 학생 등록
- 신규 자율 예약 학생 등록

권한:

- manager: 자기 지점만
- master: 지점 선택 가능

완료 조건:

- 학생 등록 후 같은 앱에서 수정/퇴원까지 전체 생명주기를 관리할 수 있어야 함
- 담당 선생님 변경 시 타 지점 선생님 선택 불가
- 정규 일정 변경 시 서버 충돌 검사 결과를 그대로 사용자에게 안내

## Phase 2. 선생님 / 지점장 관리

### 선생님 관리

- 선생님 목록
- 신규 선생님 생성
- 지점 표시
- 근무 요일/시간 조회 및 수정
- 담당 학생 목록
- 개인 월간/주간 일정 바로가기
- 이름 수정
- PIN 재설정
- 비활성화

권한:

- 신규 생성/비활성화는 우선 master 전용
- manager는 자기 지점 선생님 정보 조회 및 근무시간 관리 범위만 허용 여부 검토

### 지점장 관리

master 전용.

- 지점장 목록
- 신규 지점장 생성
- 담당 지점 변경
- 이름 수정
- PIN 재설정
- 비활성화

완료 조건:

- 기존 smoke page 없이 정식 운영 UI에서 직원 계정을 관리할 수 있어야 함
- PIN 원문은 화면에 표시하지 않음

## Phase 3. 레슨 관리 확장

현재 1회 수업 수정/취소 기능을 유지하면서 관리 화면을 확장한다.

필수 기능:

- 지점 필터
- 선생님 필터
- 학생 필터
- 학기 필터
- 월간 캘린더
- 주간 시간표
- 목록형 수업 관리 화면
- 학생별 수업 캘린더
- 관리자용 수업 직접 생성이 필요한 경우 서버 규칙에 맞춘 별도 기능으로 구현

UI에서 아래 두 작업을 명확히 분리한다.

1. 이번 수업만 변경
2. 정규 일정 자체 변경

완료 조건:

- 같은 변경 로직을 여러 화면에서 복제하지 않고 공통 lesson action 컴포넌트를 사용

## Phase 4. 학기 / 휴원 / 예약 불가 시간

### 학기 관리

- 전체 기본 학기 목록
- 시작일 / 종료일
- 휴원 기간 추가/수정/삭제
- 지점별 학기 예외 설정

권한:

- master: 전체 기본 학기 + 모든 지점 예외
- manager: 자기 지점 예외 설정 범위만 허용 여부 검토

### 예약 불가 시간

- 지점 선택
- 선생님 선택
- 날짜
- 시작/종료 시간
- 사유
- 목록 조회
- 삭제

완료 조건:

- 학생 예약 가능 시간 계산과 동일한 서버 규칙을 사용
- 기존 수업과 겹치는 경우 서버 응답 기준으로 차단/경고

## Phase 5. 지점 상세 관리

현재 지점 목록/생성 화면을 확장한다.

지점 상세:

- 지점명
- 운영 상태
- 지점장
- 선생님 수
- 수강생 수
- 선생님 관리 바로가기
- 수강생 관리 바로가기
- 학기/휴원 설정 바로가기
- 예약 불가 시간 바로가기
- 지점명 변경
- 지점 비활성화

master 전용 기능:

- 지점 생성
- 지점명 변경
- 지점 비활성화
